# AI 海龟汤（网页版）

单人就能玩的网页版海龟汤。你只看汤面，用「是／否」问题把它问出来，最后猜汤底。

本仓库是**纯前端离线版**，部署在 GitHub Pages 上直接可玩，无需服务器、无需后端。

## 在线玩

<https://ndhcunsjeh-bit.github.io/ai-turtle-soup/>

## 怎么玩

1. 看顶部「汤面」，用是／否问题问主持人
2. 主持人只回答：是 / 否 / 无关 / 无法回答 / 恭喜猜对
3. 问不出来可以点「提示」，有把握就点「猜汤底」

## 技术说明

- 判定逻辑：`ghpages.js`（受控词白名单 + 本地关键词判定）
- 题库：`data.js`（10 道题，汤底明文，任何人可查看）
- 页面逻辑：`app.js`；样式：`styles.css`
- 零依赖、无构建，纯原生 HTML/CSS/JS

> 提示：本版本汤底（答案）在源码里是公开的，想认真玩就别提前翻 `data.js`。
